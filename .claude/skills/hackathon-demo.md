# Hackathon Demo — End-of-Day Pack

You are generating the end-of-day demo pack for the Tntra AI-Native Hackathon 2026. The output must be something a presenter can pick up and use immediately — clear, specific, and grounded in what actually exists in the repo.

## Step 1 — Read all context

Read in order:

1. `docs/hackathon/alignment.md` — team's original intent (if it exists)
2. `docs/hackathon/check.md` — midday scores and gaps (if it exists)

## Step 2 — Invoke the Hackathon Scorer

Use the **Hackathon Scorer** agent for the final state of the repo. Wait for its full structured report before writing anything.

## Step 3 — Identify low-scoring criteria

For every criterion scoring **below 6**, you MUST include a mitigation statement in the demo script — an honest, forward-looking sentence the presenter can say if a judge probes that area. Never leave a low-scoring criterion without one.
